# Прототип виджета «Распределение сделок» — экраны

Блупринт интерфейсов для отрисовки в Figma и последующей привязки к коду.
Бренд KO:AGENCY: off-black `#141414` + красный `#d22730`, шрифт **Roboto**.

Легенда вайрфреймов: `[ ]` кнопка · `(•)` тумблер вкл · `( )` выкл ·
`▸` пункт меню · `●` статус-точка · `▁▃▅` столбцы графика.

## 4. Состояния (рисовать для КАЖДОГО экрана)

| Состояние | Как показать |
|---|---|
| Загрузка | скелетоны строк/плиток или спиннер |
| Пусто | иконка + текст + кнопка действия («Создайте первый шаблон») |
| Ошибка | плашка с РЕАЛЬНОЙ причиной («Сервер не отвечает. Проверьте URL») |
| Не настроено | «Укажите Server URL в настройках» |
| Сохранение | кнопка → «Сохраняется…», блокировка формы |

## 6. Привязка к коду (design → code)

- **Имя фрейма = класс:** `dist-table`, `dist-switch`, `dist-card`,
  `dist-nav__i`, `dist-av`, `dist-kpi` — переносится 1:1 в `widget.js`/`widget.css`.
- **Источники данных:** менеджеры — `AMOCRM.constant('managers')` (браузер);
  статусы/шаблоны/лог/расписания — бэкенд (`/api/status`, `/api/templates`,
  `/api/log`, `/api/schedules`).
- **Тексты — через i18n** (ru/en), помечать ключом (`status.title`), не хардкод.
- **Не рисовать данных без API** — если экрану нужен новый эндпоинт
  (Дашборд-агрегация, Заместители), пометить «нужен бэкенд», допишем.
- **Готовый эталон стилей:** превью-артефакт
  https://claude.ai/code/artifact/b5f0c8d2-8174-4284-a3ed-379659b1afb1

1. **Шаблоны** (+ модалка) — бэкенд готов, сразу привяжем.
2. **Дашборд** — эффектный, выделяет нас на фоне конкурента.
3. **Рабочее время** (+ модалка календаря).
4. **Отчёты** (3 таблицы).
5. **Заместители**, **Оплата** — по мере необходимости.
