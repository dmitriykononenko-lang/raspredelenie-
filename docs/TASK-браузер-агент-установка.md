# Задание для браузерного агента: установить и протестировать виджет «Распределение сделок» в amoCRM

**Тип исполнителя:** агент, управляющий браузером (computer-use / browser automation).
**Цель:** установить приватный виджет в amoCRM, включить его (сейчас «Отключено»),
открыть «Расширенные настройки» и проверить, что экраны **Статусы** и **Шаблоны**
работают. Вернуть отчёт со скриншотами.

**Язык интерфейса amoCRM:** русский (все кнопки/пункты — на русском).

---

## Входные данные (передаются отдельно, НЕ в этом файле)

- **URL аккаунта amoCRM:** `https://koagency.amocrm.ru`
- **Логин/пароль** для входа — получить у заказчика (секрет, не логировать).
- **Файл виджета:** `raspredelenie-widget.zip` (версия **1.0.12**) — должен быть
  доступен агенту локально для загрузки (скачать по ссылке/из чата заранее).
- **Server URL (значение поля в настройках виджета):**
  `https://raspredelenie.koagency.ru`

---

## Часть 1. Вход и переход к виджету

1. Открыть `https://koagency.amocrm.ru`, войти под выданными логином/паролем.
   *Ожидание:* загрузился рабочий стол amoCRM.
2. Перейти: **Настройки** (левое меню, шестерёнка снизу) → вкладка **Интеграции**.
3. Открыть раздел **«Установленные»** (или «Приватные интеграции»).
   *Ожидание:* видно карточку **«Распределение сделок»** со статусом
   **«Отключено»** (чёрный логотип с красными точками).

## Часть 2. Обновить архив и установить

4. Кликнуть по карточке **«Распределение сделок»** → откроется карточка интеграции.
5. Нажать **«Редактировать»** (кнопка справа вверху).
6. В форме редактирования найти загрузку файла виджета и **загрузить**
   `raspredelenie-widget.zip` (v1.0.12). Сохранить, если требуется.
   *Ожидание:* архив принят без ошибок валидации (никаких красных сообщений
   про manifest/locale/logo). Если ошибка — зафиксировать её текст и СТОП
   (вернуть заказчику).
7. Найти поле **«Server URL»** и вписать: `https://raspredelenie.koagency.ru`
8. Нажать **«Установить»** (или «Сохранить и установить»).
   *Ожидание:* статус меняется с «Отключено» на активный (как у соседней
   интеграции «Дубли от Ko:agency» — «Установлено …»).
   Если amoCRM запросит подтверждение доступа — подтвердить.

## Часть 3. Открыть полностраничный экран

9. Открыть виджет (клик по карточке) и найти пункт/кнопку
   **«Расширенные настройки»**.
   *Ожидание:* открывается страница с **чёрным сайдбаром KO:AGENCY** слева
   (лого, тумблер ONLINE, пункты меню: «Статусы распределения», «Шаблоны»,
   «Рабочее время (скоро)», «Отчёты (скоро)») и таблицей справа.
   Сделать **скриншот** этого экрана.

## Часть 4. Тест «Статусы»

10. Убедиться, что открыт пункт **«Статусы распределения»** — видна таблица
    менеджеров с тумблерами в колонке «В распределении».
11. Переключить тумблер у любого менеджера (вкл→выкл). *Ожидание:* тумблер
    меняет состояние без ошибок (красная плашка не появляется).
    Сделать **скриншот**.

## Часть 5. Тест «Шаблоны»

12. Кликнуть пункт сайдбара **«Шаблоны»**.
    *Ожидание:* заголовок «Шаблоны распределения», кнопка «+ Добавить шаблон».
    Если шаблонов нет — пустое состояние «Пока нет шаблонов».
13. Нажать **«+ Добавить шаблон»** → открывается модалка «Новый шаблон».
14. Заполнить: **Название** = `Тест — новые заявки`; **Тип** = «Round Robin»
    (сегмент-переключатель); добавить 1–2 менеджеров из выпадающего списка
    «+ Добавить менеджера» (появятся чипы-аватары).
15. Нажать **«Сохранить»**. *Ожидание:* модалка закрывается, в таблице
    появляется строка «Тест — новые заявки» с бейджем «Round Robin».
    Сделать **скриншот**.
16. Нажать иконку редактирования (карандаш) у этой строки → изменить название на
    `Тест — правка` → «Сохранить». *Ожидание:* название в таблице обновилось.
17. Нажать иконку удаления (×) → подтвердить. *Ожидание:* строка исчезла.

---

## Что вернуть заказчику (отчёт)

1. **Статус установки:** виджет активен (не «Отключено») — да/нет.
2. **Скриншоты:** (а) экран «Расширенные настройки» с сайдбаром; (б) «Статусы» с
   таблицей; (в) «Шаблоны» после создания тестового шаблона.
3. **Результат тестов:** сработали ли переключение статуса, создание/правка/
   удаление шаблона (для каждого — ок / ошибка + текст ошибки).
4. **Любые ошибки/красные плашки** — дословный текст и на каком шаге.

## Стоп-условия (не продолжать, вернуть заказчику)

- Ошибка валидации архива при загрузке (manifest/locale/logo/dp/locations).
- Виджет не переходит в активный статус после «Установить».
- Пункт «Расширенные настройки» не появляется или страница пустая/битая.
- Экран открылся, но таблицы пустые с ошибкой «Сервер недоступен» — значит
  не задан/недоступен Server URL (проверить шаг 7) или бэкенд не отвечает.
